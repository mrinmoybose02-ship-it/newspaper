★ পদ্ধতি ১ (সবচেয়ে সহজ — লোকাল XAMPP সহ সবার জন্য):
  ম্যানুয়ালি ফোল্ডার কপি করার দরকারই নেই!
  ১. শুধু ২টি ফাইল index.php-এর পাশে রাখুন:
       - index.php      (পুরোনোটার জায়গায়)
       - install_logos.php
  ২. ব্রাউজারে খুলুন: http://localhost/newspaper/install_logos.php
     → নিজে থেকেই uploads/festivals/ ফোল্ডার + ১২টি ছবি তৈরি করে দেবে
  ৩. সবুজ "সফল" মেসেজ দেখলে "ইনস্টলার ডিলিট করুন" বাটনে ক্লিক করুন
  ৪. হোমপেজে গিয়ে Ctrl+F5 — ব্যস!

★ পদ্ধতি ২ (ম্যানুয়াল):
  ১. index.php ফাইলটি সাইট রুটে পুরোনো index.php-এর জায়গায় আপলোড করুন।
  ২. "festivals" ফোল্ডারটি যেকোনো একটি জায়গায় রাখুন — দুটোই কাজ করবে (v3):

     ✅ জায়গা ① (সবচেয়ে সহজ — সাইট রুটে সরাসরি):
         C:\xampp\htdocs\newspaper\
         ├── index.php
         ├── config.php
         └── festivals\        ← এখানেই কপি করুন
             ├── maha_ashtami.png  (ইত্যাদি ৬টি লোগো)
             └── banners\          (৬টি ব্যানার)

     ✅ জায়গা ② (আদর্শ — uploads এর ভেতরে):
         C:\xampp\htdocs\newspaper\
         ├── index.php
         └── uploads\
             └── festivals\    ← অথবা এখানে
                 ├── maha_ashtami.png
                 └── banners\

     ★ v3 স্মার্ট ডিটেকশন: কোড নিজেই ফোল্ডারটি খুঁজে নেয় — কোথায়
       রাখলেন সেটা মিলিয়ে দেখার ঝামেলা নেই। একবচন "festival"
       নাম হলেও চলবে!

        ★ v2 আপডেটে নতুন ফিক্স: পুরোনো ভাঙা সেটিং থাকলেও এখন অটোমেটিক
          লোগোই দেখাবে — তাই সাধারণত ধাপ ৩ লাগবেই না।

ধাপ ৪: ব্রাউজার ক্যাশ ক্লিয়ার করুন বা Ctrl+F5 (মোবাইলে একবার বন্ধ করে খুলুন)।
        CDN/Cloudflare থাকলে একবার ক্যাশ পিউর্জ করুন।

ধাপ ৫: এখনও সমস্যা হলে festival_check.php-এর স্ক্রিনশট পাঠান —
        সাথে ফোল্ডার রিপোর্টটাও। সাথে সাথে ঠিক করে দেব।
